       ```typescript
       import { Router } from "express";

       const router = Router();

       router.get(["/health", "/api/health"], (_req, res) => {
         res.status(200).json({
           status: "ok",
           timestamp: new Date().toISOString(),
           uptime: process.uptime(),
         });
       });

       export default router;
       ```

    2. Update `server/src/app.ts` (created in Plan 01) to import and mount the health router:
       - Add: `import healthRouter from "./routes/health.js";` (NOTE: .js extension required for NodeNext)
       - Add: `app.use(healthRouter);` inside createApp before the return
       - Keep the existing express.json() middleware and AppDeps interface

    3. Create `server/src/index.ts` — the server entry point:
       - FIRST LINE must be: `import "dotenv/config";` (loads .env before any other imports — critical for config.ts to see env vars)
       - Second import: `import { config, warnOnBlankConfig, requireConfigValues } from "./services/config.js";` (.js extension for NodeNext)
       - Then import neo4j, createApp, createServer
       - In `async function main()`:
         a. Create Neo4j driver: `neo4j.driver(config.NEO4J_URI, neo4j.auth.basic(config.NEO4J_USERNAME, config.NEO4J_PASSWORD))`
         b. Log non-blocking startup warnings for blank integration keys (AWS/Datadog/MiniMax)
         c. For Neo4j boot connectivity check:
            - if `SKIP_NEO4J_CONNECTIVITY_CHECK=1` and non-production, skip with warning
            - otherwise call `requireConfigValues(["NEO4J_URI", "NEO4J_USERNAME", "NEO4J_PASSWORD"], "Neo4j connectivity check")` before `verifyConnectivity()`
            - then run `await driver.verifyConnectivity()` and fail if it throws
         d. Call `createApp({ driver })` to get the Express app
         e. `createServer(app).listen(config.PORT, () => console.log(...))`
       - Wrap `main()` in `.catch()` for fatal startup errors
       - Add explicit guard: only allow Neo4j skip in non-production.

    4. Verify the full boot:
       - Run `npm run dev` from project root (will start both client and server via concurrently)
       - Server should start on port 3001
       - Client should start on port 5173
       - `curl http://localhost:3001/health` should return `{"status":"ok","timestamp":"...","uptime":...}`
       - `curl http://localhost:3001/api/health` should return the same payload (proxy-compatible path)
       - Kill the dev servers after verification
