  <name>Task 1: Create MiniMax TTS service</name>
  <files>
    server/src/services/tts.ts
  </files>
  <action>
Create `server/src/services/tts.ts`:
- Export `TTSResult` interface: `{ audioBuffer: Buffer; audioFormat: string; durationMs: number }`
- Export `async function generateTTS(text: string): Promise<TTSResult>`
- Import `config` from `./config.js` (same pattern as existing code in `index.ts`)
- Build URL: `https://api.minimax.io/v1/t2a_v2?GroupId=${config.MINIMAX_GROUP_ID}`
- POST with headers: `Authorization: Bearer ${config.MINIMAX_API_KEY}`, `Content-Type: application/json`
- Request body:
  ```json
  {
    "model": "speech-2.8-hd",
    "text": text,
    "stream": false,
    "output_format": "hex",
    "voice_setting": {
      "voice_id": "English_CaptivatingStoryteller",
      "speed": 1,
      "vol": 1,
      "pitch": 0
    },
    "audio_setting": {
      "sample_rate": 32000,
      "format": "mp3",
      "channel": 1
    }
  }
  ```
  NOTE: Voice settings start at neutral (speed 1, pitch 0) for CaptivatingStoryteller since it's already a dramatic narrator voice. Tune after listening to the pre-generated audio.
- Add `signal: AbortSignal.timeout(30_000)` for 30s timeout
- Check `response.ok` — throw on HTTP error
- Parse JSON response, check `json.base_resp.status_code !== 0` — throw on MiniMax application error (research pitfall #3)
- Decode audio: `Buffer.from(json.data.audio, 'hex')`
- Return `{ audioBuffer, audioFormat: json.extra_info.audio_format ?? 'mp3', durationMs: json.extra_info.audio_length ?? 0 }`
  </action>
  <verify>
Verify `server/src/services/tts.ts` exports `generateTTS` and `TTSResult`.
  </verify>
  <done>
TTS service accepts arbitrary text and returns decoded mp3 Buffer via MiniMax T2A v2 using CaptivatingStoryteller voice.
  </done>
