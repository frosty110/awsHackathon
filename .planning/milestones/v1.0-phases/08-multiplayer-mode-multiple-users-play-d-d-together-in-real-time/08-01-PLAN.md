       - `ServerToClientEvents` interface with these events:
         - `room:created` — `(data: { code: string }) => void`
         - `room:state` — `(state: RoomStatePayload) => void`
         - `room:player-joined` — `(player: PlayerPayload) => void`
         - `room:player-disconnected` — `(data: { socketId: string; displayName: string }) => void`
         - `room:player-reconnected` — `(data: { socketId: string }) => void`
         - `room:started` — `() => void`
         - `room:error` — `(data: { message: string }) => void`
         - `turn:timer-start` — `(data: { durationMs: number; endsAt: number }) => void`
         - `turn:player-submitted` — `(data: { socketId: string }) => void`
         - `dm:stream-start` — `() => void`
         - `dm:chunk` — `(data: { text: string }) => void`
         - `dm:stream-end` — `(data: { fullText: string }) => void`
         - `dm:error` — `(data: { message: string }) => void`
         - `chat:message` — `(data: ChatMessagePayload) => void`
         - `chat:reaction` — `(data: { messageId: string; emoji: string; fromSocketId: string; fromName: string }) => void`
         - `dice:rolled` — `(data: { socketId: string; displayName: string; result: number }) => void`
       - `ClientToServerEvents` interface:
         - `room:create` — `(data: { displayName: string; characterClass: string }) => void`
         - `room:join` — `(data: { code: string; displayName: string; characterClass: string }) => void`
         - `room:ready` — `() => void`
         - `turn:submit-action` — `(data: { action: string }) => void`
         - `chat:send` — `(data: { text: string }) => void`
         - `chat:react` — `(data: { messageId: string; emoji: string }) => void`
         - `dice:roll` — `(data: { result: number }) => void`
       - `SocketData` interface: `{ roomCode: string; displayName: string; characterClass: string }`
       - `RoomStatePayload` type: `{ code: string; phase: RoomPhase; players: PlayerPayload[] }`
       - `PlayerPayload` type: `{ socketId: string; displayName: string; characterClass: string; connected: boolean; ready: boolean; submittedAction: boolean }` (note: submittedAction is boolean, not the text — per Claude's Discretion, actions are hidden until DM responds)
       - `ChatMessagePayload` type: `{ id: string; fromSocketId: string; fromName: string; fromClass: string; text: string; timestamp: number }`
       - `RoomPhase` type: `"lobby" | "playing" | "collecting-actions" | "dm-responding"`

         - Stores in module `io` variable
         - Returns `io`
         - NOTE: Use Vite proxy for dev (ws: true), so CORS origin is just the dev server. In production, the client serves from the same origin.
       - Export `{ io }` as named export

<task type="auto">
  <name>Task 2: Create room store and add Vite WebSocket proxy</name>
  <files>
    server/src/services/roomStore.ts
    client/vite.config.ts
  </files>
  <action>
    1. Create `server/src/services/roomStore.ts`:
       - Import `customAlphabet` from `nanoid`
       - Define types:
         - `RoomPhase` = `"lobby" | "playing" | "collecting-actions" | "dm-responding"` (also export)
         - `Player` type: `{ socketId: string; displayName: string; characterClass: string; connected: boolean; ready: boolean; submittedAction: string | null }`
         - `Room` type: `{ code: string; conversationId: string; phase: RoomPhase; players: Map<string, Player>; timerStartedAt: number | null; timerHandle: ReturnType<typeof setTimeout> | null; currentDmText: string }`
           - `currentDmText` accumulates the DM stream for late-joiners
       - Module-level `const rooms = new Map<string, Room>()`
       - `generateUniqueRoomCode()`: use `customAlphabet("ABCDEFGHJKLMNPQRSTUVWXYZ", 6)` (omit I, O). Loop `do { code = gen() } while (rooms.has(code))`. Return code.
       - `createRoom(code: string, conversationId: string): Room` — creates room in lobby phase, empty players Map, null timer fields, empty currentDmText. Stores in `rooms` map. Returns room.
       - `getRoom(code: string): Room | undefined` — simple get.
       - `deleteRoom(code: string): void` — clears timer if set, deletes from map.
       - `addPlayer(code: string, player: Player): boolean` — gets room, checks room exists AND has fewer than 4 players. Returns false if room full or not found. Adds player to map keyed by socketId.
       - `removePlayer(code: string, socketId: string): void` — removes player from room's players map.
       - `markPlayerDisconnected(code: string, socketId: string): void` — sets `connected = false`.
       - `markPlayerReconnected(code: string, socketId: string): void` — sets `connected = true`.
       - `markPlayerReady(code: string, socketId: string): void` — sets `ready = true`.
       - `submitAction(code: string, socketId: string, action: string): boolean` — sets submittedAction. Returns true if successful.
       - `allActionsSubmitted(code: string): boolean` — returns true if every connected player has a non-null submittedAction.
       - `resetActions(code: string): void` — sets all players' submittedAction to null.
       - `getRoomStatePayload(code: string): RoomStatePayload | null` — converts room to serializable payload (converts players Map to PlayerPayload array with `submittedAction: !!player.submittedAction` to hide action text).
       - `getConnectedPlayerCount(code: string): number`
       - `getAllReadyCount(code: string): number`
       - Export all functions and types.

    2. Update `client/vite.config.ts`:
       - Add `/socket.io` proxy entry alongside existing `/api` proxy:
         ```typescript
         "/socket.io": {
           target: "http://localhost:3001",
           ws: true,
           changeOrigin: true,
         },
         ```
       - Note: target is port 3001 (not 3000 — the server runs on 3001 per project config).
  </action>
