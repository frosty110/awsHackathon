  <action>
    Create `client/src/hooks/useMultiplayerRoom.ts`:

    - Import `{ useEffect, useState, useCallback, useRef }` from React
    - Import `socket` from `../services/socket`
    - Import types from `../types/multiplayer`

    State managed by the hook:
    - `roomCode: string | null`
    - `phase: RoomPhase` (default: "lobby")
    - `players: MultiplayerPlayer[]`
    - `dmMessages: Array<{ id: string; role: "dm"; content: string; isStreaming?: boolean }>` — accumulated DM messages (each stream-end produces a complete message)
    - `currentStreamText: string` — text being streamed (cleared on stream-end)
    - `timerEndsAt: number | null` — epoch ms when current timer expires
    - `hasSubmitted: boolean` — whether local player submitted this round
    - `chatMessages: ChatMessage[]` — player chat messages
    - `chatReactions: Map<string, Array<{ emoji: string; fromName: string }>>` — message reactions
    - `diceRolls: Array<{ socketId: string; displayName: string; result: number }>` — recent dice rolls
    - `error: string | null`

    useEffect (runs once on mount, cleanup on unmount):
    - Register named handler functions for each event (use `function onXxx()` declarations, not anonymous — needed for exact cleanup):
      - `room:state` -> set roomCode, phase, players from payload
      - `room:player-joined` -> add player to players array
      - `room:player-disconnected` -> mark player disconnected in array
      - `room:player-reconnected` -> mark player reconnected
      - `room:started` -> set phase to "playing"
      - `room:error` -> set error
      - `turn:timer-start` -> set timerEndsAt from payload.endsAt, set hasSubmitted = false
      - `turn:player-submitted` -> update players array to mark socketId as submitted
      - `dm:stream-start` -> set phase to "dm-responding", reset currentStreamText to ""
      - `dm:chunk` -> append text to currentStreamText
      - `dm:stream-end` -> push complete message to dmMessages, clear currentStreamText, set phase per subsequent events
      - `dm:error` -> set error message, clear streaming state
      - `chat:message` -> push to chatMessages
      - `chat:reaction` -> add to chatReactions map
      - `dice:rolled` -> push to diceRolls (keep last 20 max)
    - Return cleanup: `socket.off(event, handler)` for every registered handler

    Callbacks (useCallback):
    - `submitAction(action: string)`: emit `turn:submit-action` with `{ action }`, set hasSubmitted = true
    - `sendChat(text: string)`: emit `chat:send` with `{ text }`. Also push to local chatMessages immediately (sender sees own message without round-trip, since socket.to() excludes sender).
    - `sendReaction(messageId: string, emoji: string)`: emit `chat:react` with `{ messageId, emoji }`
    - `rollDice(result: number)`: emit `dice:roll` with `{ result }`

    Return all state + callbacks.

    CRITICAL: All `socket.on()` calls must have matching `socket.off()` in cleanup with the SAME named function reference. Use `function` declarations, not arrow functions stored in variables that might get recreated.
  </action>
