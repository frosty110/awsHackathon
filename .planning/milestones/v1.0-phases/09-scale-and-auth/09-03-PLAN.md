   ```
   yarn workspace server add jsonwebtoken bcryptjs express-rate-limit rate-limit-redis
   yarn workspace server add -D @types/jsonwebtoken @types/bcryptjs
   ```
   Note: express-session and connect-redis are NOT needed — auth is purely JWT-stateless. No session cookies.

2. Create `server/src/middleware/auth.ts`:
   - Import `jwt` from `jsonwebtoken` (default import).
   - Import types from Express.
   - Import `{ config }` from `../services/config.js`.
   - Define and export `interface AuthenticatedRequest extends Request { userId?: string; username?: string; }`.
   - Export `function requireAuth(req, res, next)`:
     - Extract `Authorization: Bearer <token>` header.
     - If missing or malformed: `res.status(401).json({ error: "Missing or invalid token" }); return;`.
     - `jwt.verify(token, config.JWT_SECRET)` — if throws, return 401 `{ error: "Token invalid or expired" }`.
     - On success: set `req.userId` and `req.username` from payload, call `next()`.
   - Export `function optionalAuth(req, res, next)`:
     - Same as requireAuth but does NOT return 401 on missing/invalid token — just calls `next()` without setting userId.
     - This allows routes to work for both authenticated and unauthenticated users (needed for gradual auth rollout — existing players can still play without auth).

3. Create `server/src/routes/auth.ts`:
   - Import `Router` from `express`, `jwt` from `jsonwebtoken`, `bcrypt` from `bcryptjs`.
   - Import `{ config }` from `../services/config.js`.
   - Import `{ redisClient, isRedisAvailable }` from `../services/redis.js`.
   - Import `{ logEvent }` from `../services/logger.js`. NOTE: logger.ts already exists and exports logEvent — verify the import path resolves correctly.
   - User storage: Redis hashes at key `user:{username}` with fields `userId`, `username`, `passwordHash`.
   - If Redis unavailable, fall back to in-memory array (same as research example, but log warning).
   - In-memory fallback: `const inMemoryUsers: Array<{ userId: string; username: string; passwordHash: string }> = []`.

   - `POST /api/auth/register`:
     - Parse `{ username, password }` from body.
     - Validate: username 3-20 chars alphanumeric + underscore only. Password 6+ chars.
     - Check if username exists (Redis `hGetAll` or in-memory find).
     - Hash password: `await bcrypt.hash(password, 12)` (12 rounds).
     - Generate `userId = crypto.randomUUID()`.
     - Store: Redis `hSet(`user:${username}`, { userId, username, passwordHash })` or in-memory push.
     - Return `201 { message: "registered", userId, username }`.
     - Log: `logEvent("info", "auth.register_success", { username })`.

   - `POST /api/auth/login`:
     - Parse `{ username, password }` from body.
     - Lookup user (Redis `hGetAll` or in-memory find).
     - If not found or `bcrypt.compare` fails: return `401 { error: "Invalid credentials" }`. Do NOT say whether username or password was wrong.
     - Sign JWT: `jwt.sign({ userId, username }, config.JWT_SECRET, { expiresIn: "7d" })`.
     - Return `200 { token, userId, username }`.
     - Log: `logEvent("info", "auth.login_success", { username })`.

   - Export `default router`.

4. Create `server/src/middleware/rateLimiter.ts`:
   - Import `{ rateLimit }` from `express-rate-limit`.
   - Import `{ RedisStore }` from `rate-limit-redis` (named export per research).
   - Import `{ redisClient, isRedisAvailable }` from `../services/redis.js`.
   - Import `type { AuthenticatedRequest }` from `./auth.js`.

   - Helper function to create rate limiter store: if `isRedisAvailable()`, use `new RedisStore({ sendCommand: (...args: string[]) => redisClient.sendCommand(args), prefix })`. Otherwise, use default MemoryStore (built into express-rate-limit).

   - Export `chatRateLimiter = rateLimit({...})`:
     - `windowMs: 60 * 1000` (1 minute).
     - `limit: 20` (20 requests per minute per user).
     - `standardHeaders: "draft-7"`, `legacyHeaders: false`.
     - `keyGenerator: (req) => (req as AuthenticatedRequest).userId ?? req.ip ?? "unknown"`.
     - `store`: Redis or memory (from helper).
     - `message: { error: "Too many chat requests, slow down" }`.

   - Export `narrateRateLimiter = rateLimit({...})`:
     - Same config but `limit: 10` (TTS is expensive).
     - Different prefix: `"rl:narrate:"`.
     - `message: { error: "Too many narrate requests, slow down" }`.
