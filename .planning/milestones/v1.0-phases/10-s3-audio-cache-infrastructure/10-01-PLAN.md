**Part A — Create `server/src/services/audioCache.ts`:**

Create a new file with three exports: `buildCacheKey`, `getAudio`, `putAudio`.

1. **S3Client singleton** at module scope:
   ```typescript
   import { S3Client, GetObjectCommand, PutObjectCommand, NoSuchKey } from "@aws-sdk/client-s3";
   const s3 = new S3Client({ region: config.AWS_REGION || "us-east-1" });
   ```
   Follows the same singleton pattern as bedrock.ts. SDK auto-picks up AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_SESSION_TOKEN from env.

2. **buildCacheKey(text, voice, mood, model)** -> string:
   - Build pre-hash string: `${model}|${voice}|${mood ?? "none"}|${text}`
   - SHA-256 hash, hex digest, truncate to 32 chars (not 16 — more collision resistance for S3 keys)
   - Return `tts/v1/${hash}.mp3` — the `tts/v1/` prefix namespaces objects for lifecycle policies
   - Import types `CharacterVoice`, `SceneMood`, `TTSModel` from `./tts.js`

3. **getAudio(key)** -> Promise<Buffer | null>:
   - Wrap in `tracer.trace("s3.audio_cache.get", { resource: key }, async (span) => { ... })`
   - Use `GetObjectCommand` directly (NOT HeadObject + GetObject — saves a round trip per cache hit)
   - On success: call `response.Body!.transformToByteArray()`, set `span.setTag("cache.result", "hit")` and `span.setTag("cache.bytes", bytes.byteLength)`, return `Buffer.from(bytes)`
   - Catch `NoSuchKey` -> set `span.setTag("cache.result", "miss")`, return `null`
   - On other errors: set `span.setTag("error", true)`, re-throw
   - IMPORTANT: Use `tracer.trace()` (NOT `tracer.llmobs.trace()`) — llmobs is reserved for LLM calls only

4. **putAudio(key, audioBuffer, meta)** -> Promise<void>:
   - Wrap in `tracer.trace("s3.audio_cache.put", { resource: key }, async (span) => { ... })`
   - `PutObjectCommand` with:
     - `ContentType: "audio/mpeg"`
     - `CacheControl: "max-age=31536000, immutable"` (content-addressed keys never change)
     - `Metadata: { voice, mood, model, generatedAt: new Date().toISOString() }`
   - Set `span.setTag("cache.bytes", audioBuffer.byteLength)`

5. Guard against missing bucket config: if `config.S3_AUDIO_CACHE_BUCKET` is empty string, `getAudio` should return null immediately and `putAudio` should return void immediately (no S3 calls). Log a warning once at module load if bucket is unconfigured.

**Part B — Wire audioCache into tts.ts as L2 cache:**

Modify `server/src/services/tts.ts` to add S3 as L2 behind the existing in-memory Map (L1). The in-memory Map stays for zero-latency recent hits. The cache lookup order becomes: L1 Map -> L2 S3 -> MiniMax API.

1. Add import at top:
   ```typescript
   import { buildCacheKey as buildS3Key, getAudio, putAudio } from "./audioCache.js";
   ```

2. In `generateTTS()`, modify the cache block (lines ~129-162 in current tts.ts):

   **Cache lookup (replace existing Map-only lookup):**
   ```typescript
   const preHashKey = buildTTSCacheKey(text, voice, options.mood, model);
   const cacheKey = hashKey(preHashKey);

   // L1: in-memory Map (existing behavior, zero latency)
   const l1Cached = ttsCache.get(cacheKey);
   if (l1Cached && Date.now() - l1Cached.createdAt < TTS_CACHE_TTL_MS) {
     ttsCacheHits++;
     logEvent("info", "tts.cache_hit", { cacheKey, source: "memory", ... });
     return l1Cached.result;
   }

   // L2: S3 (durable, cross-instance)
   const s3Key = buildS3Key(text, voice, options.mood, model);
   let s3Buffer: Buffer | null = null;
   try {
     s3Buffer = await getAudio(s3Key);
   } catch (err) {
     // S3 unavailable — degrade gracefully, treat as miss
     logEvent("warn", "tts.s3_cache_get_failed", { s3Key, error: String(err) });
   }

   if (s3Buffer) {
     ttsCacheHits++;
     const s3Result: TTSResult = { audioBuffer: s3Buffer, audioFormat: "mp3", durationMs: 0 };
     // Promote to L1
     ttsCache.set(cacheKey, { result: s3Result, createdAt: Date.now() });
     logEvent("info", "tts.cache_hit", { cacheKey, s3Key, source: "s3", ... });
     return s3Result;
   }

   ttsCacheMisses++;
   logEvent("info", "tts.cache_miss", { cacheKey, s3Key, ... });
   ```

   **After MiniMax API call succeeds (replace existing "Store in cache" block ~233-240):**
   ```typescript
   // L1: store in memory
   evictStaleTTSEntries();
   if (ttsCache.size >= TTS_CACHE_MAX_SIZE) {
     const oldestKey = ttsCache.keys().next().value;
     if (oldestKey) ttsCache.delete(oldestKey);
   }
   ttsCache.set(cacheKey, { result, createdAt: Date.now() });

   // L2: store in S3 (fire-and-forget, non-blocking)
   const s3KeyForPut = buildS3Key(text, voice, options.mood, model);
   putAudio(s3KeyForPut, result.audioBuffer, {
     voice: VOICE_MAP[voice],
     mood: options.mood ?? "none",
     model,
   }).catch((err) =>
     logEvent("warn", "tts.s3_cache_put_failed", { s3Key: s3KeyForPut, error: String(err) })
   );
   ```

   Key points:
   - S3 put is fire-and-forget (`.catch()` with logging, not awaited) — does NOT add latency to TTS response
   - S3 get failure degrades gracefully to MiniMax API call (treated as cache miss)
   - L1 hit short-circuits before S3 check (no unnecessary S3 calls for recent audio)
   - S3 hits are promoted to L1 for subsequent zero-latency access
