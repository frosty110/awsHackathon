**M-7: x-request-id validation in `server/src/services/logger.ts`**

Replace the `buildRequestId` function (lines 71-74) with:

```typescript
const REQUEST_ID_RE = /^[a-zA-Z0-9\-_]{1,128}$/;

export function buildRequestId(headerValue: string | undefined): string {
  const trimmed = headerValue?.trim();
  return trimmed && REQUEST_ID_RE.test(trimmed) ? trimmed : crypto.randomUUID();
}
```

This validates the header value against an alphanumeric regex (allowing hyphens and underscores) with a max length of 128 characters. Invalid or missing values get a fresh UUID. This prevents log injection attacks via crafted x-request-id headers.
