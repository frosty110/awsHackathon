**client/src/services/saves.ts** — Create fetch wrappers following the pattern in auth.ts (using authHeaders and API_BASE):

```typescript
import { API_BASE } from './apiBase';
import { authHeaders } from './auth';

export interface SaveRecord {
  conversationId: string;
  name: string;
  characterClass: string;
  pronouns: string;
  turnCount: number;
  savedAt: number;
  lastPlayedAt: number;
  mode: 'single' | 'multi';
}
```

Functions:
1. `listSaves(): Promise<SaveRecord[]>` — GET /api/saves, returns `data.saves` array. On error, return empty array (graceful degradation).
2. `createSave(conversationId: string, name: string, characterClass?: string, pronouns?: string, mode?: 'single' | 'multi'): Promise<SaveRecord | null>` — POST /api/saves with JSON body. Returns the created save on success, null on error.
3. `deleteSave(conversationId: string): Promise<boolean>` — DELETE /api/saves/:conversationId. Returns true on success.
4. `renameSave(conversationId: string, name: string): Promise<boolean>` — PUT /api/saves/:conversationId/name with JSON body `{ name }`. Returns true on success.

All functions include `...authHeaders()` in headers. Handle 401 with `refreshAccessToken()` retry (same pattern as useSSEChat.ts fetch calls). Use try/catch for network errors.

const resumeSession = useCallback((
  savedConversationId: string,
  characterClass?: string,
  pronouns?: string
) => {
  // Set refs that normally come from startAdventure
  conversationId.current = savedConversationId;
  if (characterClass) characterClassRef.current = { name: characterClass } as CharacterClass;
  if (pronouns) pronounsRef.current = pronouns;
  // Messages stay empty — the DM will generate a contextual "you resume your adventure" prompt
  // on the first sendMessage call, since the server has the full conversation history
