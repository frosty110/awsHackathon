  <action>
1. Create `client/src/types/chat.ts`:
   ```typescript
   export type MessageRole = 'dm' | 'player' | 'dice';

   export interface Message {
     id: string;
     role: MessageRole;
     content: string;
     isStreaming?: boolean;
   }

   export type AppState = 'idle' | 'adventure';
   ```
   The `isStreaming` field is for Phase 4 (SSE streaming indicator). The `dice` role distinguishes dice roll messages from regular player messages per user decision (dice emoji prefix, distinct visual treatment).

2. Create `client/src/hooks/useSSEChat.ts`:
   - Import `useState`, `useCallback`, `useRef`, `useEffect` from React and `Message` from types
   - Define `MOCK_RESPONSES` array with 3+ thematic DM responses (tavern arrival, barkeep dialogue, goblin encounter)
   - Implement `useSSEChat()` returning `{ messages, isLoading, sendMessage, reset }`:
     - Track pending mock response timeout with `useRef<ReturnType<typeof setTimeout> | null>(null)`.
     - `sendMessage(content: string)`: Creates a player message (role `'player'`), OR if content starts with the dice emoji, creates a dice message (role `'dice'`). Appends to messages. Sets isLoading=true. Clears any existing pending timeout, then sets a new 1200ms timeout (simulating Bedrock response time) that appends a mock DM response and sets isLoading=false.
     - `reset()`: Clears any pending timeout, clears messages array, sets isLoading=false
     - Add cleanup `useEffect(() => () => { ...clear timeout... }, [])` so delayed callbacks do not fire after unmount/reset.
   - This is a STUB — Phase 4 replaces the mock delay block with real SSE fetch. The hook's external interface MUST remain `{ messages, isLoading, sendMessage, reset }` exactly.

   IMPORTANT: Use `crypto.randomUUID()` for message IDs (available in modern browsers, desktop-only per user decision). Detect dice messages with `content.startsWith('\u{1F3B2}')` (the dice emoji character).

3. Create `client/src/hooks/useChatScroll.ts`:
   - Import `useRef`, `useEffect` from React and `Message` from types
   - Implement `useChatScroll(messages: Message[])` returning a `RefObject<HTMLDivElement | null>`:
     - Creates a `bottomRef` via `useRef<HTMLDivElement | null>(null)`
     - `useEffect` with `[messages]` dependency calls `bottomRef.current?.scrollIntoView({ behavior: 'smooth' })`
     - Returns bottomRef
   - Usage: consumer places `<div ref={bottomRef} />` as last child of the scrollable message container
  </action>
