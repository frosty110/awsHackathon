Create all four components in `client/src/components/`. Each component uses Tailwind utility classes from the @theme tokens defined in Plan 01.

**MessageBubble.tsx:**
- Props: `{ message: Message }`
- DM messages (`role === 'dm'`): left-aligned (`justify-start`), `bg-dm-bubble`, `font-fell`, italic, relaxed leading — the narrator voice
- Player messages (`role === 'player'`): right-aligned (`justify-end`), `bg-player-bubble`, `font-sans`, smaller text — the player voice
- Dice messages (`role === 'dice'`): right-aligned, `bg-blood/70`, `font-sans`, semibold, with `border border-blood-light` — stands out as game action
- All bubbles: `text-parchment`, `max-w-[75%]`, `px-4 py-3`, `rounded-lg`
- Text only in bubbles — NO timestamps, labels, or metadata (locked decision)

**ChatWindow.tsx:**
- Props: `{ messages: Message[], isLoading: boolean }`
- Scrollable container: `flex-1 overflow-y-auto` with padding
- Maps `messages` to `<MessageBubble>` components keyed by `message.id`
- Loading indicator: When `isLoading` is true, render a left-aligned bubble-like element with "The Dungeon Master is thinking..." in `font-fell italic` with `animate-pulse-glow` (subtle glow/pulse per user decision)
- Auto-scroll: Call `useChatScroll(messages)` and place `<div ref={bottomRef} />` as last child inside the scrollable container
- Import `useChatScroll` from hooks and `MessageBubble` from components

**MessageInput.tsx:**
- Props: `{ onSend: (content: string) => void, disabled: boolean }`
- Horizontal row: text input + Send button
- Text input: `flex-1`, dark background, `text-parchment`, `font-sans`, placeholder "What do you do?", `border border-blood/30`
- Send button: `font-cinzel`, `text-parchment`, `bg-blood/30 hover:bg-blood/50`, `border border-blood`
- On submit (Enter key or button click): call `onSend(text)` and clear the input field
- Input and button are disabled when `disabled` is true (prevents stacking messages while DM responds — locked decision)
- Use local `useState` for the input text value

**DiceRoller.tsx:**
- Props: `{ onRoll: () => void, disabled: boolean, needsRoll: boolean }`
- Full-width button below the input row (locked decision: button below input, not beside it)
- Text: dice emoji + "Roll the Dice" in `font-cinzel text-parchment`
- Styling: `border-blood bg-blood/30 hover:bg-blood/50`
- Shake animation: Local `useState` for `shaking`. On click, set shaking=true, after 400ms (matching dice-shake keyframe duration) set shaking=false and call `onRoll()`. Apply `animate-dice-shake` class when shaking.
- Pulse glow: Apply `animate-pulse-glow` class when `needsRoll` is true AND not disabled (locked decision: button glows when DM's last message suggests a roll)
- Disabled state: `opacity-40 cursor-not-allowed` when disabled
- Guard: return early from click handler if disabled or already shaking

Rewrite `client/src/App.tsx` to compose the full chat interface. This is the top-level component that manages app state and connects all pieces.

**Structure (see RESEARCH.md Pattern: App-Level State Machine for reference):**

1. **State management:**
   - `const [appState, setAppState] = useState<AppState>('idle')` — idle shows Start Adventure, adventure shows chat
   - `const { messages, isLoading, sendMessage, reset } = useSSEChat()`
   - Derive `needsRoll`: check last DM message content against `/roll|dice|check|save|attack/i` regex. One-liner: `const lastDM = [...messages].reverse().find(m => m.role === 'dm')?.content ?? ''; const needsRoll = /roll|dice|check|save|attack/i.test(lastDM);`

2. **Handlers:**
   - `handleStart`: sets appState to 'adventure'
   - `handleReset`: calls `reset()` then sets appState to 'idle'
   - `handleRollDice`: calls `sendMessage('🎲 I roll the dice!')`  — the dice emoji prefix triggers 'dice' role in useSSEChat (locked decision: Roll Dice sends a regular chat message, no frontend dice generation)

3. **Layout — single screen, centered container (locked decisions):**
   - Outer: `min-h-screen flex items-center justify-center` — centers the container
   - Container: `w-full max-w-3xl h-screen flex flex-col bg-surface border-x border-blood/30` — focused app-like column (700-800px = max-w-3xl is 768px)
   - Dark overlay: Add a `div` with `absolute inset-0 bg-black/60` behind the container content to provide the rgba(0,0,0,0.6) overlay for readability over the background image (locked decision). The body already has the background image from index.css. Use `relative` on the outer wrapper so the overlay positions correctly.

4. **Header (locked decision):**
   - `<header>` with flex row: left side "AI Dungeon Master" in `font-cinzel text-2xl text-parchment tracking-widest`, right side "Powered by AWS Bedrock" in `font-sans text-xs text-parchment/50`
   - Reset button: visible only in adventure state, `font-cinzel text-xs text-blood-light hover:text-parchment` — clears chat and returns to Start Adventure state
   - Bottom border: `border-b border-blood/30`

5. **Main area:**
   - **Idle state:** Center a "Start Adventure" button — `font-cinzel text-xl text-parchment px-8 py-4 border border-blood bg-blood/20 hover:bg-blood/40 tracking-widest`. No chat input, no messages visible (locked decision).
   - **Adventure state:**
     - `<ChatWindow messages={messages} isLoading={isLoading} />`
     - Input area at bottom with `border-t border-blood/30`:
       - First row: `<MessageInput onSend={sendMessage} disabled={isLoading} />`
       - Second row: `<DiceRoller onRoll={handleRollDice} disabled={isLoading} needsRoll={needsRoll} />`
       (Locked decision: text input + Send on first row, Roll Dice on second row)
