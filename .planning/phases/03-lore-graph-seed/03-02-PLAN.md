Create `data/seed.ts` following the research-recommended pattern. The script must:

**1. Load environment:**
```typescript
import dotenv from 'dotenv';
import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';
import neo4j from 'neo4j-driver';
```

Use `dotenv.config({ path: join(dirname(fileURLToPath(import.meta.url)), '..', '.env') })` to load `.env` from the repo root regardless of cwd. This avoids Pitfall 6 from research.

**2. Load lore.json:**
Use `readFileSync` + `JSON.parse` (NOT static import — avoids ESM JSON import issues per Pitfall 4):
```typescript
const __dirname = dirname(fileURLToPath(import.meta.url));
const lore = JSON.parse(readFileSync(join(__dirname, 'lore.json'), 'utf8'));
```

**3. Create driver:**
```typescript
const uri = process.env.NEO4J_URI;
const user = process.env.NEO4J_USERNAME;
const password = process.env.NEO4J_PASSWORD;

if (!uri || !user || !password) {
  console.error('Missing NEO4J_URI, NEO4J_USERNAME, or NEO4J_PASSWORD in .env');
  process.exit(1);
}

const driver = neo4j.driver(uri, neo4j.auth.basic(user, password));
```
Note: AuraDB URIs use `neo4j+s://` (TLS). The `.env.example` already documents this.

**4. seed() function — three phases in order:**

Phase A — Create uniqueness constraints (idempotent via IF NOT EXISTS):
```typescript
const labels = ['Character', 'Location', 'Item', 'Quest', 'Faction'];
for (const label of labels) {
  await driver.executeQuery(
    `CREATE CONSTRAINT ${label.toLowerCase()}_name_unique IF NOT EXISTS FOR (n:${label}) REQUIRE n.name IS UNIQUE`,
    {},
    { database: 'neo4j' }
  );
}
console.log('Constraints created.');
```

Phase B — UNWIND batch MERGE per label (idempotent via MERGE):
```typescript
const labelMap: Record<string, string> = {
  characters: 'Character',
  locations: 'Location',
  items: 'Item',
  quests: 'Quest',
  factions: 'Faction',
};

for (const [key, label] of Object.entries(labelMap)) {
  const nodes = lore[key] ?? [];
  if (nodes.length === 0) continue;
  const result = await driver.executeQuery(
    `UNWIND $nodes AS props
     MERGE (n:${label} {name: props.name})
     ON CREATE SET n += props
     ON MATCH SET n += props
     RETURN n.name AS name`,
    { nodes },
    { database: 'neo4j' }
  );
  console.log(`  ${label}: ${result.records.length} nodes merged`);
}
```
Use `ON MATCH SET n += props` so re-runs update attributes (not just skip).

Phase C — MERGE relationships after all nodes exist:
```typescript
for (const rel of lore.relationships ?? []) {
  await driver.executeQuery(
    `MATCH (a:${rel.fromLabel} {name: $from})
     MATCH (b:${rel.toLabel} {name: $to})
     MERGE (a)-[r:${rel.type}]->(b)
     ON CREATE SET r += $props`,
    { from: rel.from, to: rel.to, props: rel.properties ?? {} },
    { database: 'neo4j' }
  );
}
console.log(`  Relationships: ${lore.relationships?.length ?? 0} merged`);
```
Note: `rel.type` is templated directly into Cypher (cannot be parameterized). This is safe because lore.json is controlled input.

**5. Entrypoint with cleanup:**
```typescript
seed()
  .then(() => console.log('Seed complete.'))
  .catch((err) => { console.error('Seed failed:', err); process.exit(1); })
  .finally(() => driver.close());
```
The `finally` block ensures `driver.close()` is always called — prevents the script from hanging (Pitfall 2).
