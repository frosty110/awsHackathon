**server/src/services/bedrock.ts:**
- Import `BedrockRuntimeClient`, `ConverseStreamCommand`, and `type Message as BedrockMessage` from `@aws-sdk/client-bedrock-runtime`
- Import `type Response` from `express`
- Import `config` from `./config.js`
- Create a singleton `bedrockClient = new BedrockRuntimeClient({ region: config.AWS_REGION })` at module scope
- Export `async function streamBedrockToSSE(messages: BedrockMessage[], systemPrompt: string, res: Response, signal: AbortSignal): Promise<string>`:
  - Create `ConverseStreamCommand` with `modelId: config.BEDROCK_MODEL_ID`, `system: [{ text: systemPrompt }]`, the messages array, and `inferenceConfig: { maxTokens: 1024, temperature: 0.85 }`
  - Call `bedrockClient.send(command, { abortSignal: signal })`
  - Iterate `response.stream` with `for await...of`
  - On each `contentBlockDelta`, extract `event.contentBlockDelta?.delta?.text`
  - If delta exists, append to `fullText` accumulator and write SSE: `res.write(\`data: ${JSON.stringify({ text: delta })}\n\n\`)` -- guard with `if (!res.writableEnded)`
  - Break if `signal.aborted`
  - Return `fullText` string (caller persists as assistant message)

**server/src/services/conversationStore.ts:**
- Export type `ChatMessage = { role: 'user' | 'assistant'; content: string }`
- Create `const store = new Map<string, ChatMessage[]>()` at module scope
- Export `function getOrCreate(conversationId?: string): { id: string; history: ChatMessage[] }` -- generates UUID if no id, initializes empty array if not in map
- Export `function appendMessage(id: string, message: ChatMessage): void` -- pushes to store
- Export `function toBedrockMessages(history: ChatMessage[])` -- slices to last 12 entries, maps each to `{ role, content: [{ text: m.content }] }` matching Bedrock Converse message shape

Use `crypto.randomUUID()` for ID generation (available in Node 19+). Follow the `.js` extension convention for imports (ESM).

**server/src/routes/chat.ts:**
- Import `Router` from `express`, `z` from `zod`
- Import `getOrCreate`, `toBedrockMessages`, `appendMessage` from `../services/conversationStore.js`
- Import `streamBedrockToSSE` from `../services/bedrock.js`
- Define `ChatBodySchema` using Zod: `conversationId` (string, uuid, optional), `message` (string, min 1, max 2000), `diceResult` (number, int, min 1, max 20, optional)
- Define `DM_SYSTEM_PROMPT` constant -- compact D&D dungeon master prompt:
  "You are a dramatic and immersive Dungeons & Dragons Dungeon Master narrating a dark fantasy adventure. Speak in second person ("you"), use vivid sensory detail, and keep responses concise (2-4 sentences). When a dice roll result is provided, narrate the outcome using the number explicitly: 1-5 is a critical failure with consequences, 6-15 is a partial success with complications, 16-20 is a great success worthy of celebration. Current scenario: The Shattered Crown tavern -- a goblin ambush lurks nearby."
- Create `chatRouter = Router()`
- Add `chatRouter.post('/chat', async (req, res) => { ... })`:
  1. Validate body with `ChatBodySchema.safeParse(req.body)` -- return 400 JSON on failure
  2. Get/create conversation via `getOrCreate(conversationId)`
  3. Augment message with dice result if `diceResult != null`: append `\n[Dice roll result: ${diceResult}. Narrate the outcome: 1-5 failure, 6-15 partial success, 16-20 great success.]`
  4. Append user message to history via `appendMessage(id, { role: 'user', content: augmentedMessage })`
  5. Set SSE headers BEFORE any async work: Content-Type text/event-stream, Cache-Control no-cache, Connection keep-alive, X-Accel-Buffering no. Call `res.flushHeaders()`
  6. Write first SSE event with `conversationId`: `data: ${JSON.stringify({ conversationId: id })}\n\n`
  7. Create AbortController, set 30s timeout to `controller.abort()`, wire `req.on('close', () => { controller.abort(); clearTimeout(timeout); })`
  8. In try: convert history to Bedrock format via `toBedrockMessages`, call `streamBedrockToSSE`, persist result via `appendMessage(id, { role: 'assistant', content: fullText })`
  9. In catch: if not AbortError, write SSE error event (guard `!res.writableEnded`)
  10. In finally: `clearTimeout(timeout)`, write `data: [DONE]\n\n` and `res.end()` (both guarded with `!res.writableEnded`)
- Export `chatRouter` as default
