Create `server/src/services/rag.ts` with these exports and internal functions:

**Imports:**
- `import type { Driver } from 'neo4j-driver';`
- `import neo4j from 'neo4j-driver';`
- Use `.js` extension on any local imports (NodeNext resolution).

**Module-level state:**
- `let entityDictionary: Set<string> = new Set();` -- loaded once at startup.

**ENTITY_ALIASES constant** (Record<string, string>) mapping demo keywords to canonical entity names:
- `'tavern'` -> `'The Shattered Crown Tavern'`
- `'shattered crown'` -> `'The Shattered Crown Tavern'`
- `'ring'` -> `'Ring of Ashwick'`
- `'ashwick ring'` -> `'Ring of Ashwick'`
- `'gorm'` -> `'Gorm'`
- `'barkeep'` -> `'Gorm'`
- `'dwarf behind the bar'` -> `'Gorm'`
- `'goblin'` -> `'Goblin Scout'`
- `'goblins'` -> `'Goblin Scout'`
- `'northern caves'` -> `'Northern Caves'`
- `'caves'` -> `'Northern Caves'`
- `'ashwick'` -> `'Ashwick'`
- `'quest'` -> `'Retrieve the Ring of Ashwick'`

**NARRATIVE_ATTRS constant** (string array) controlling which node properties appear in lore context:
`['description', 'atmosphere', 'personality', 'motivation', 'speakingStyle', 'background', 'lore', 'status', 'behavior', 'weapon', 'hp']`

**`initRag(driver: Driver | null): Promise<void>`** (exported):
- If `driver` is null, log `[rag] driver is null - RAG disabled (no lore will be injected)` and return.
- Run `driver.executeQuery('MATCH (n) WHERE n.name IS NOT NULL RETURN DISTINCT n.name AS name', {}, { routing: neo4j.routing.READ, database: 'neo4j' })`.
- Map records to strings and store in `entityDictionary`.
- Log `[rag] entity dictionary loaded: ${entityDictionary.size} entries`.
- Wrap entire body in try/catch. On error, log `[rag] failed to load entity dictionary, RAG disabled:` + error. Do NOT rethrow.

**`extractEntities(userMessage: string): string[]`** (internal, not exported):
- Lowercase the user message once.
- Iterate ENTITY_ALIASES: if `lower.includes(alias)`, add the canonical name to a `Set<string>`.
- Iterate entityDictionary: if `lower.includes(name.toLowerCase())`, add to the Set.
- Return `[...found].slice(0, 5)` (cap at 5 to prevent prompt bloat).

**`fetchLoreNodes(driver: Driver, entityNames: string[]): Promise<Record<string, unknown>[]>`** (internal):
- Run `driver.executeQuery()` with Cypher: `MATCH (n) WHERE n.name IN $names RETURN n { .* } AS node, labels(n) AS nodeLabels LIMIT 20`.
- Pass `{ names: entityNames }` as parameters, `{ routing: neo4j.routing.READ, database: 'neo4j' }` as config.
- Map records: spread `r.get('node')` as `Record<string, unknown>`, add `_labels: r.get('nodeLabels') as string[]`.
- Return the array.

**`assembleLoreContext(nodes: Record<string, unknown>[]): string`** (internal):
- If nodes is empty, return `''`.
- Start with `['[LORE CONTEXT - ground your narration in these facts:]']`.
- For each node: add `\n${label}: ${name}` where label is `(node._labels as string[])?.[0] ?? 'Entity'` and name is `node.name as string`.
- For each attr in NARRATIVE_ATTRS: if `node[attr] != null`, add `  ${attr}: ${node[attr]}`.
- Return `lines.join('\n')`.

**`buildLoreContext(driver: Driver | null, userMessage: string): Promise<string>`** (exported):
- If `driver` is null, return `''`.
- Wrap in try/catch. On error, log `[rag] retrieval failed, continuing without lore:` + error, return `''`.
- Call `extractEntities(userMessage)`. If empty array, return `''`.
- Call `fetchLoreNodes(driver, entities)`.
- Return `assembleLoreContext(nodes)`.

Do NOT use `any` types. Cast Neo4j record results explicitly with `as Record<string, unknown>` and `as string[]`.
