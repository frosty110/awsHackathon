Create `server/src/services/tts.ts`:
- Export `TTSResult` interface: `{ audioBuffer: Buffer; audioFormat: string; durationMs: number }`
- Export `async function generateTTS(text: string): Promise<TTSResult>`
- Import `config` from `./config.js` (same pattern as existing code in `index.ts`)
- Build URL: `https://api.minimax.io/v1/t2a_v2?GroupId=${config.MINIMAX_GROUP_ID}`
- POST with headers: `Authorization: Bearer ${config.MINIMAX_API_KEY}`, `Content-Type: application/json`
- Request body:
  ```json
  {
    "model": "speech-2.8-hd",
    "text": text,
    "stream": false,
    "output_format": "hex",
    "voice_setting": {
      "voice_id": "English_Persuasive_Man",
      "speed": 0.9,
      "vol": 1,
      "pitch": -2
    },
    "audio_setting": {
      "sample_rate": 32000,
      "format": "mp3",
      "channel": 1
    }
  }
  ```
- Add `signal: AbortSignal.timeout(30_000)` for 30s timeout
- Check `response.ok` — throw on HTTP error
- Parse JSON response, check `json.base_resp.status_code !== 0` — throw on MiniMax application error (research pitfall #3)
- Decode audio: `Buffer.from(json.data.audio, 'hex')`
- Return `{ audioBuffer, audioFormat: json.extra_info.audio_format ?? 'mp3', durationMs: json.extra_info.audio_length ?? 0 }`

Create `server/src/routes/narrate.ts`:
- Import `Router` from `express`
- Import `generateTTS` from `../services/tts.js`
- Define `OPENING_MONOLOGUE` constant with text from research:
  ```
  Welcome, brave soul. The night is dark, the road is long, and the Shattered Crown tavern stands before you — the last warm light before the wilderness swallows everything. Step inside. Your adventure begins now.
  ```
- Create `router.post(['/narrate', '/api/narrate'], ...)` handler:
  - Call `generateTTS(OPENING_MONOLOGUE)`
  - Set `Content-Type: audio/mpeg` (hardcode — we always request mp3)
  - Set `Content-Length` to `audioBuffer.length`
  - `res.send(audioBuffer)`
  - Catch block: `console.error` the error, return `res.status(500).json({ error: 'TTS generation failed' })`
- Export default router

Update `server/src/app.ts`:
- Add `import narrateRouter from './routes/narrate.js';` (follow the existing healthRouter import pattern)
- Add `app.use(narrateRouter);` after the existing `app.use(healthRouter);` line

Do NOT add rate limiting here — keep it simple for the hackathon. Do NOT add Datadog spans — Phase 6 handles that.
