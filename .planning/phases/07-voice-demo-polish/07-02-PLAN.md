  <action>
Create `client/src/components/AudioPlayer.tsx`:

Props interface:
```typescript
interface AudioPlayerProps {
  onAdventureStart: () => void;
}
```

Component state:
- `useState<'idle' | 'loading' | 'playing'>('idle')` for button state
- `useRef<HTMLAudioElement | null>(null)` for audio element reference

`handleStartAdventure` async function (called from onClick):
1. Guard: `if (status !== 'idle') return;`
2. Set status to `'loading'`
3. Try block:
   a. `const response = await fetch('/api/narrate', { method: 'POST' })`
   b. If `!response.ok`, throw
   c. `const arrayBuffer = await response.arrayBuffer()`
   d. `const blob = new Blob([arrayBuffer], { type: 'audio/mpeg' })`
   e. `const objectUrl = URL.createObjectURL(blob)`
   f. `const audio = new Audio(objectUrl)`
   g. Set `audioRef.current = audio`
   h. Set status to `'playing'`
   i. Call `onAdventureStart()` — show chat UI IMMEDIATELY, do not wait for audio to finish (research pitfall #4)
   j. `audio.play().catch(err => console.error('[AudioPlayer] play() failed:', err))`
   k. `audio.addEventListener('ended', () => { URL.revokeObjectURL(objectUrl); audioRef.current = null; })` — cleanup blob URL (research pitfall #5)
4. Catch block:
   a. `console.error('[AudioPlayer] narrate fetch failed:', error)`
   b. Set status to `'idle'`
   c. Call `onAdventureStart()` — MUST still start adventure on TTS failure (CLAUDE.md reliability requirement)

Render:
- Button text: `'The Dungeon Master is speaking...'` when loading, `'Start Adventure'` otherwise
- Button classes: same as existing Start Adventure in App.tsx — `font-cinzel text-xl text-parchment px-8 py-4 border border-blood bg-blood/20 hover:bg-blood/40 tracking-widest`
- Add `disabled:opacity-60 disabled:cursor-not-allowed` for disabled state
- `disabled={status === 'loading'}`
- `onClick={handleStartAdventure}`

IMPORTANT: The entire fetch → blob → audio.play() chain MUST stay inside the async onClick handler — NOT in a useEffect. This preserves Chrome's user gesture trust for autoplay (research finding).

Export: `export function AudioPlayer({ onAdventureStart }: AudioPlayerProps)`
