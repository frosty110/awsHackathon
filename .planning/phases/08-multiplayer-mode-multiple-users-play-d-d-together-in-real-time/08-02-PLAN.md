  <action>
    1. Install client dependency:
       ```bash
       cd client && npm install socket.io-client@4.8.3
       ```

    2. Create `client/src/services/socket.ts`:
       - Import `{ io, Socket }` from `socket.io-client`
       - Export `const socket: Socket = io({ autoConnect: false })`
       - No URL needed — Vite proxy handles routing `/socket.io` to the backend. Using `io()` with no URL defaults to the page origin.

    3. Create `client/src/types/multiplayer.ts`:
       - Define and export `CharacterClassId` type: `"warrior" | "mage" | "rogue" | "cleric" | "ranger" | "bard"`
       - Define and export `CHARACTER_CLASSES` constant array with 6 entries, each having:
         - `id: CharacterClassId`
         - `name: string` (display name, capitalized)
         - `icon: string` (emoji: Warrior="swords", Mage="sparkles", Rogue="dagger", Cleric="star", Ranger="bow", Bard="musical note")
         - `color: string` (Tailwind text color class — Warrior="text-red-400", Mage="text-blue-400", Rogue="text-purple-400", Cleric="text-yellow-300", Ranger="text-green-400", Bard="text-pink-400")
       - Define and export `RoomPhase` type: `"lobby" | "playing" | "collecting-actions" | "dm-responding"`
       - Define and export `MultiplayerPlayer` type: `{ socketId: string; displayName: string; characterClass: CharacterClassId; connected: boolean; ready: boolean; submittedAction: boolean }`
       - Define and export `RoomState` type: `{ code: string; phase: RoomPhase; players: MultiplayerPlayer[] }`
       - Define and export `ChatMessage` type: `{ id: string; fromSocketId: string; fromName: string; fromClass: CharacterClassId; text: string; timestamp: number }`
       - Define and export `getClassColor(classId: CharacterClassId): string` helper that returns the Tailwind color class from CHARACTER_CLASSES.
       - Define and export `getClassIcon(classId: CharacterClassId): string` helper that returns the emoji from CHARACTER_CLASSES.
  </action>

  <name>Task 2: Create ModeSelect and MultiplayerLobby components</name>
  <files>

  <action>
    1. Create `client/src/components/ModeSelect.tsx`:
       - Props: `{ onSinglePlayer: () => void; onMultiplayer: () => void }`
       - Renders two large clickable cards/buttons in the dark fantasy theme:
         - "Solo Adventure" — single sword icon, brief tagline "Face the darkness alone", calls onSinglePlayer
         - "Multiplayer Party" — group/party icon, brief tagline "Join forces with fellow adventurers", calls onMultiplayer
       - Use existing Tailwind theme tokens: font-cinzel for headings, font-fell for body, text-parchment, bg-surface, border-blood/30
       - Cards should have hover:border-dm-gold/50 transition, centered layout
       - Title at top: "Choose Your Path" in font-cinzel text-dm-gold

    2. Create `client/src/components/MultiplayerLobby.tsx`:
       - Props: `{ onGameStart: (roomState: RoomState) => void; onBack: () => void }`
       - Internal state:
         - `step`: `"choose"` | `"create"` | `"join"` | `"lobby"` (flow: choose -> create/join -> lobby)
         - `displayName`: string input
         - `characterClass`: CharacterClassId | null
         - `joinCode`: string input (for join flow)
         - `roomState`: RoomState | null
         - `error`: string | null
       - **Choose step**: Two buttons — "Create Room" and "Join Room", plus a "Back" button calling onBack
       - **Create/Join step**: Form with:
         - Display name text input (required, max 20 chars)
         - Character class picker: render all 6 CHARACTER_CLASSES as selectable cards/buttons showing icon + name with class-specific color borders when selected. Duplicate classes allowed (per locked decision).
         - For "Join" flow only: Room code input (6 chars, uppercase, auto-uppercased on input)
         - "Enter the Fray" submit button
         - On submit:
           - Connect socket if not connected: `socket.connect()`
           - For create: `socket.emit("room:create", { displayName, characterClass })`
           - For join: `socket.emit("room:join", { code: joinCode, displayName, characterClass })`
       - **Lobby step** (shown after room:created or room:state received):
         - Display room code prominently (large font-cinzel text-dm-gold, monospace tracking-widest) for sharing
         - Player list showing each player's: display name, character class icon + name (in class color), ready status (checkmark or waiting), connection status (green dot or grey)
         - "Ready" toggle button (emits `socket.emit("room:ready")`)
         - Player count: "N/4 adventurers gathered"
       - Socket event listeners (registered in useEffect with proper cleanup):
         - `room:created` -> set roomState from payload, move to lobby step
         - `room:state` -> update roomState
         - `room:player-joined` -> update roomState players
         - `room:player-disconnected` -> update player connected status
         - `room:player-reconnected` -> update player connected status
         - `room:started` -> call `onGameStart(roomState!)`
         - `room:error` -> set error message
       - Dark fantasy styling consistent with existing components. Room code display: inside a bordered box with subtle glow.
  </action>
