<task type="auto">
  <name>Task 1: Rewrite conversationStore to Redis-backed with in-memory fallback</name>
  <files>server/src/services/conversationStore.ts</files>
  <action>
Rewrite `server/src/services/conversationStore.ts` entirely:

1. Import `{ redisClient, isRedisAvailable }` from `./redis.js`.

2. Keep the existing type definitions (`ChatMessage`, `Conversation`) — they are the public contract.

3. Keep the in-memory `Map<string, Conversation>` as fallback store for when Redis is unavailable.

4. Set `CONVERSATION_TTL_SECONDS = 7 * 24 * 60 * 60` (7 days). Conversations expire after 7 days idle.

5. Redis key pattern: `conv:{conversationId}` — stores JSON-serialized Conversation.

6. Rewrite ALL functions to be async. The signatures change:
   - `getOrCreate(conversationId?, characterClass?, pronouns?)` -> `Promise<Conversation>`
   - `getCharacterClass(conversationId)` -> `Promise<string | undefined>`
   - `getPronouns(conversationId)` -> `Promise<string | undefined>`
   - `appendMessage(conversationId, message)` -> `Promise<void>`
   - `getWindowedHistory(conversationId, maxTurns?)` -> `Promise<ChatMessage[]>`

7. Implementation pattern for each function:
   - Check `isRedisAvailable()`.
   - If Redis available: use `redisClient.get(key)` / `redisClient.set(key, JSON.stringify(data), { EX: CONVERSATION_TTL_SECONDS })`.
   - If Redis unavailable: fall back to the in-memory Map (same logic as current code).
   - On Redis access: call `redisClient.expire(key, CONVERSATION_TTL_SECONDS)` to refresh TTL on read.

8. `getOrCreate` implementation:
   - Generate `id = conversationId ?? crypto.randomUUID()`.
   - If Redis: try `redisClient.get(`conv:${id}`)`. If found, parse JSON, update characterClass/pronouns if provided and not already set, `redisClient.set()` back, return. If not found, create new, `redisClient.set()`, return.
   - If no Redis: use existing Map logic (current implementation).

9. `appendMessage` implementation:
   - If Redis: `redisClient.get(key)`, parse, push message, `redisClient.set(key, ...)`. If key not found, throw Error (same as current).
   - If no Redis: use Map.

10. `getWindowedHistory` implementation:
    - If Redis: `redisClient.get(key)`, parse, return `history.slice(-maxTurns)`.
    - If no Redis: use Map.

11. `getCharacterClass` / `getPronouns`:
    - If Redis: `redisClient.get(key)`, parse, return field.
    - If no Redis: use Map.

12. Add explicit return type annotations on ALL functions — TypeScript will flag missing `await` in callers with strict mode.
