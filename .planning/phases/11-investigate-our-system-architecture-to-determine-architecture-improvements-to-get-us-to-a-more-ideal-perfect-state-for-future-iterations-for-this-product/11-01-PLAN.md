IMPORTANT: Check how each router defines its paths. If routers use `router.post(['/chat', '/api/chat'], ...)`, then the limiter must be applied in the router file or as route-specific middleware. The cleanest approach:

- Same for narrateRouter and musicRouter

Actually, the simplest correct approach is to apply limiters in app.ts before the routers for the `/api/*` prefix paths:
- Before chatRouter: add chatLimiter as middleware
- Before narrateRouter: add narrateLimiter as middleware
- Before musicRouter: add musicLimiter as middleware

Read the existing route files to confirm their path patterns, then apply limiters accordingly.
