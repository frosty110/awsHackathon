1. Add constants at the top:
   ```typescript
   const MAX_ENTRIES = 10_000;
   const MAX_AGE_MS = 24 * 60 * 60 * 1000; // 24 hours
   ```

2. Add an `evictStaleEntries()` function:
   ```typescript
   function evictStaleEntries(): void {
     const cutoff = Date.now() - MAX_AGE_MS;
     // Remove entries older than 24h from the front (entries are chronologically ordered)
     while (entries.length > 0 && entries[0].timestamp < cutoff) {
       entries.shift();
     }
     // Hard cap: if still over MAX_ENTRIES, remove oldest
     if (entries.length > MAX_ENTRIES) {
       entries.splice(0, entries.length - MAX_ENTRIES);
     }
   }
   ```

3. Call `evictStaleEntries()` at the START of every `record*` function (recordBedrockUsage, recordTtsUsage, recordMusicUsage, recordVideoUsage) — this is a lazy eviction pattern that runs only when new data arrives, avoiding the need for a timer.

4. The `entries` array stays as-is (module-level). The eviction is additive — no behavioral change to summarize() or any consumer.

5. Export `evictStaleEntries` for testing purposes (but no caller needs it directly).
