**H-7: Graceful shutdown in `server/src/index.ts`**

Add imports for Redis at the top of the file (after existing imports):
```typescript
import { redisClient, isRedisAvailable } from "./services/redis.js";
```

Capture the `io` return value from `initSocketIO(server)`. The current code at line 83 is:
```typescript
await initSocketIO(server);
```

Change to:
```typescript
const io = await initSocketIO(server);
```

Replace the shutdown handler (lines 90-95) with:

```typescript
const shutdown = async (signal: string) => {
  console.log(`[shutdown] ${signal} received, closing gracefully...`);
  // 1. Close Socket.IO first — sends disconnect packets while HTTP is still up
  io.close();
  // 2. Stop accepting new HTTP connections
  server.close();
  // 3. Close Neo4j driver
  if (driver) await driver.close();
  // 4. Flush pending Redis commands and close TCP connection
  if (isRedisAvailable()) await redisClient.quit();
  process.exit(0);
};
```

CRITICAL ordering: `io.close()` MUST come before `server.close()`. Socket.IO needs the HTTP server running briefly to send WebSocket disconnect packets to all connected clients. Calling `server.close()` first would kill the underlying transport before Socket.IO can gracefully tear down sessions.

**H-10: DM trigger idempotency guard in `server/src/sockets/turnHandlers.ts`**

In `triggerDMOpening` (line 140-144): Replace:
```typescript
const room = getRoom(roomCode);
if (!room) return;

room.phase = "dm-responding";
```

With:
```typescript
const room = getRoom(roomCode);
if (!room || room.phase === "dm-responding") return; // idempotency guard
room.phase = "dm-responding";
```

In `triggerDMResponse` (line 227-231): Same change. Replace:
```typescript
const room = getRoom(roomCode);
if (!room) return;

room.phase = "dm-responding";
```

With:
```typescript
const room = getRoom(roomCode);
if (!room || room.phase === "dm-responding") return; // idempotency guard
room.phase = "dm-responding";
```

IMPORTANT: The `room.phase = "dm-responding"` assignment MUST remain as the very next statement after the guard check (before any `await`). In Node.js single-threaded event loop, synchronous code between two `await` points cannot be preempted. But two setTimeout callbacks can fire in the same microtask batch, and both could pass a guard that only checks `room.phase !== "dm-responding"` if neither has set the phase yet. By placing the phase assignment immediately after the null/phase check (no `await` in between), we guarantee the second invocation sees the updated phase synchronously.

**H-13: Room deletion cleanup in `server/src/sockets/roomHandlers.ts`**

In the `disconnect` handler, at lines 267-270, replace:

```typescript
// Clean up completely abandoned rooms
if (getConnectedPlayerCount(roomCode) === 0) {
  deleteRoom(roomCode);
}
```

With:

```typescript
// Clean up completely abandoned rooms
if (getConnectedPlayerCount(roomCode) === 0) {
  const abandonedRoom = getRoom(roomCode);
  if (abandonedRoom) {
    // Clear the action collection timer if still running
    if (abandonedRoom.timerHandle !== null) {
      clearTimeout(abandonedRoom.timerHandle);
      abandonedRoom.timerHandle = null;
    }
    // If DM is mid-stream, emit error to any remaining sockets (should be none, but defensive)
    if (abandonedRoom.phase === "dm-responding") {
      io.to(roomCode).emit("dm:error", { message: "All players disconnected." });
    }
  }
  deleteRoom(roomCode);
}
```

This ensures:
1. The 30-second action timer is cleared, preventing a timer callback from firing on a deleted room
2. If the DM was actively streaming via Bedrock, a dm:error event is emitted (the Bedrock stream will naturally fail when it tries to access the deleted room's properties)

NOTE: We do NOT add an AbortController for the Bedrock stream here. The code review marks H-13 as "easy" effort. Adding AbortController would require modifying room store types and the Bedrock streaming call chain, which is medium effort and out of scope. The Bedrock call will naturally timeout (45s max) when the room it tries to write to no longer exists.
