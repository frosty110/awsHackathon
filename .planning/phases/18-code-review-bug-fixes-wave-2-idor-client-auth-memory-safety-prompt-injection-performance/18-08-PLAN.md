  <name>Task 1: Password complexity + per-username lockout</name>
  <files>server/src/routes/auth.ts</files>
  <action>
    1. Password complexity — add to the register endpoint after the length check:
       ```typescript
       const PASSWORD_COMPLEXITY = /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)/;
       if (!PASSWORD_COMPLEXITY.test(password)) {
         res.status(400).json({ error: "Password must contain uppercase, lowercase, and a digit" });
         return;
       }
       ```
       - This is in addition to the existing 8-128 character length check.
       - Add the same check to login validation if password doesn't match complexity (fail fast with generic "Invalid credentials" — don't reveal requirements on login).

    2. Per-username account lockout — add to the login endpoint:
       - Module-level constant: `const MAX_LOGIN_ATTEMPTS = 5;` and `const LOCKOUT_DURATION_S = 900;` (15 minutes).
       - Before checking the password, check the lockout counter:
         ```typescript
         const lockoutKey = `login-attempts:${username}`;
         let attempts = 0;

         if (isRedisAvailable()) {
           const raw = await redisClient.get(lockoutKey);
           attempts = raw ? parseInt(raw, 10) : 0;
         } else {
           attempts = inMemoryLoginAttempts.get(username) ?? 0;
         }

         if (attempts >= MAX_LOGIN_ATTEMPTS) {
           logEvent("warn", "auth.account_locked", { username });
           res.status(429).json({ error: "Account temporarily locked. Try again later." });
           return;
         }
         ```
       - On failed login (password mismatch), increment the counter:
         ```typescript
         if (isRedisAvailable()) {
           await redisClient.incr(lockoutKey);
           await redisClient.expire(lockoutKey, LOCKOUT_DURATION_S);
         } else {
           inMemoryLoginAttempts.set(username, attempts + 1);
         }
         ```
       - On successful login, clear the counter:
         ```typescript
         if (isRedisAvailable()) {
           await redisClient.del(lockoutKey);
         } else {
           inMemoryLoginAttempts.delete(username);
         }
         ```
       - Add in-memory fallback: `const inMemoryLoginAttempts = new Map<string, number>();`
  </action>
  <verify>
    - `npx tsc --noEmit` compiles clean.
    - `npm test` passes.
    - `grep "PASSWORD_COMPLEXITY\|lockout" server/src/routes/auth.ts` returns matches.
  </verify>
  <done>
    - Password requires at least one uppercase, one lowercase, and one digit.
    - Per-username lockout after 5 failed attempts, 15-minute duration.
    - Lockout counter stored in Redis (or in-memory fallback).
  </done>
