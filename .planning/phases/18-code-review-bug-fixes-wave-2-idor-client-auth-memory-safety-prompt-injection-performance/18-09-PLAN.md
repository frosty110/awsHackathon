         ```typescript
         export const MessageBubble = React.memo(function MessageBubble({ message, ...props }: MessageBubbleProps) {
           // useMemo for content processing if any computed values exist
           const displayContent = useMemo(() => {
             // Any content transformation that currently happens inline

           }, [message.content]);

           // ... rest of component using displayContent instead of message.content
         });
         ```
       - React.memo will skip re-renders when props haven't changed. Since Message objects are typically stable (created once and pushed to array), this prevents re-renders during typing.
       - If the component has any expensive computed values (parsing markdown, syntax highlighting, etc.), wrap them in `useMemo`.

       - Find where TTS audio Object URLs are created (the `onDmTtsReady` handler).
       - Track created Object URLs in a `useRef<string[]>([])`:
         ```typescript
         const objectUrlsRef = useRef<string[]>([]);
         ```
       - When creating a blob URL, push it to the ref:
         ```typescript
         const url = URL.createObjectURL(blob);
         objectUrlsRef.current.push(url);
         ```
       - Add cleanup on unmount:
         ```typescript
         useEffect(() => {
           return () => {
             objectUrlsRef.current.forEach(url => URL.revokeObjectURL(url));
             objectUrlsRef.current = [];
           };
         }, []);
         ```
       - Also revoke URLs in any error/cleanup paths.
