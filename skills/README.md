# Project Skill Files

This folder stores project-local, tooling-focused skills for the hackathon workflow.

## Available skills

- `skills/datadog-dashboard-operator/SKILL.md`
- `skills/datadog-llmobs-operator/SKILL.md`
- `skills/bedrock-runtime-operator/SKILL.md`

## Intended use

1. Use Datadog dashboard skills when creating or updating dashboards and monitors.
2. Use Datadog LLMObs skills when validating trace bootstrap and LLM observability flow.
3. Use Bedrock runtime skills when implementing or changing Bedrock invocation/stream logic.
4. Use Neo4j RAG skills when implementing lore retrieval and prompt-context injection.

## Notes

1. Skill organization is by tooling responsibility, not by agent name.
2. Keep these skills aligned with `.planning` architecture contracts and demo scope.
